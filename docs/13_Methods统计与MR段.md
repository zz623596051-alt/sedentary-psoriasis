# Methods 统计分析与孟德尔随机化（供合并进正文）

> 依据：`07_Results初稿.md` v0.3（n = 15,676，病例 455）＋ `12_双向MR结果报告.md`
> 报告规范：STROBE（观察臂）／STROBE-MR（遗传臂，**清单见 §S4**）

---

## 2.1 软件与版本

所有分析在 R 4.5.2（Windows x64）中完成，使用 `survey`（复杂抽样加权）、
`splines`（限制性立方样条）、`dplyr`/`tidyr`（数据整理）、`ggplot2` 3.5+
（作图）与 `TwoSampleMR` 0.7.11（孟德尔随机化）包。NHANES 原始数据经
`nhanesA` 1.4.1 下载并缓存为本地 RDS 文件；孟德尔随机化所需汇总统计来自
FinnGen R12 公开发布（`storage.googleapis.com/finngen-public-data-r12`）
与 GWAS Catalog（`ftp.ebi.ac.uk/pub/databases/gwas`）。

## 2.2 观察性分析：加权与协变量

分析采用美国全国代表性样本：NHANES 2009–2010、2011–2012 与 2013–2014
三个周期合并。**MCQ070（"Ever been told you have psoriasis?"）仅在这三个
周期采集**（2009-2010 年新增，2015-2016 年停用），故分析窗口由此确定。

**复杂抽样设计**：以 `PSU` 为初级抽样单元、以 `SDMVSTRA` 为层，构建分层
聚类设计对象；三个周期的 2 年期权重除以周期数后合并，并对仅含单个 PSU 的层
应用 `survey.lonely.psu = "adjust"`。所有估计量、方差与 *p* 值均由
`svyglm` / `svymean` / `svychisq` 在该设计下计算。

**协变量集（主模型共 10 个）**：年龄、性别、种族/族裔（5 类）、教育水平
（5 类）、家庭收入贫困比（PIR）、吸烟状态（从不/既往/现在）、每日酒精摄入
量（g）、糖尿病、高血压。**BMI 与 CRP 未纳入主模型**，因其为所检验的中介
变量（见 §2.4）。

**总胆固醇未纳入主模型**，尽管在 Table 1 中报告：该变量缺失 9.4%，且不是
暴露—结局关系的合理混杂因素。剔除后主模型 EPV = 32.5。

**模型规格与样本量一致性**：报告的分析样本（n = 15,676）即为模型实际使用的
样本数；排除条件与协变量清单在代码中强制对齐，并设有自动断言，
防止出现"报告 n 与模型 n 不一致"的情况。完整病例中的银屑病病例 455 例，
患病率 2.90%。

## 2.3 暴露、结局与多重比较

**两个主要暴露在分析计划中预先指定**：体力活动（每 1,000 MET-min/周）
与久坐时间（每 60 min/日）。**多重比较校正的检验家族即定义为这两个主要
暴露的连续型估计**（n = 2），并以 Benjamini–Hochberg 法控制 FDR。
这一预先指定是主结果可被解释为"设计使然"而非"多次捕捞"的前提：
若把论文中报告的全部 9 个暴露检验视为单一家族，久坐关联在 FDR 校正后将
不再显著（*p* = 0.098）。

**次要暴露**（PA 四分位、久坐四分位、加速度计客观测量）**未纳入校正家族**，
其 *p* 值按探索性解释报告。

## 2.4 剂量反应与敏感性分析

**限制性立方样条**：3 个自由度（3 个节点），暴露作 log1p 变换（体力活动），
参考值取暴露中位数。**非线性以"线性模型 vs 样条模型"的 Wald 检验判定**
（体力活动 *P* = 0.62；久坐 *P* = 0.21），而非样条项的整体显著性检验——
后者回答的是"暴露是否与结局相关"，不是"是否偏离线性"。

**敏感性分析**包括：加速度计客观测量（中重度银屑病、用药确认病例、银屑病
关节炎）。**须明确说明**：这些结局的病例数分别为 62、38 与 35 例，
对应 EPV 分别为 4.1、2.5 与 2.3，**均远低于 EPV ≥ 10 的要求**，
因此只能作为**探索性提示**，不具备检出关联的能力。**不得**将其表述为
"敏感性分析结果一致，结论稳健"。

**缺失数据**：主要协变量的缺失以完整病例分析处理。主要缺失来源为 PIR
（占银屑病结局可得者的 8.95%）。**已比较纳入者与被排除者的结局发生率**：
银屑病患病率分别为 2.90%（纳入）与 2.70%（排除），χ² *P* = 0.70，
提示排除与结局无差异关联；被排除者略年长（51.7 vs 49.2 岁）
且体力活动略低（2,796 vs 2,977 MET-min/周）。**敏感性分析**：剔除 PIR 协变量以纳入缺失收入者，样本量增至 17,201，
主估计基本不变（久坐 OR 1.059，95% CI 1.011–1.109；
体力活动 OR 0.996，95% CI 0.980–1.011）。

**中介分析（探索性，不作推断）**：以 BMI 与 hs-CRP 为中介，采用在层内重抽
PSU 的聚类 bootstrap（500 次）估计间接效应。**总效应接近零时中介比例在
数学上不可解释**，且两法估计方向不一致，因此**本文不报告中介比例作为
结论**。CRP 缺失 67.4%，该中介模型仅含 32% 的样本。**该分析为探索性，
不作任何推断。**

## 2.5 孟德尔随机化

### 2.5.1 工具变量的构建

由于 OpenGWAS 用于程序化构建工具变量的端点在研究期间不可用，
**两侧数据均取自公开汇总统计**：

| 环节 | 来源 |
|---|---|
| 正向暴露 | GWAS Catalog `GCST90104339`「Leisure screen time」，n = 526,725 |
| 反向暴露 | FinnGen R12 `L12_PSORIASIS`，12,760 例 |
| 正向结局 | FinnGen R12 `L12_PSORIASIS`（12,760 例）、`L12_PSORI_VULG`（7,912 例）、`M13_PSORIARTH`（4,290 例） |
| 反向结局 | UK Biobank `ukb-b-5192`「Time spent watching television (TV)」，n = 437,887；`ukb-b-4779`「Plays computer games」，n = 462,433 |

**筛选流程（正向暴露）**：GWAS Catalog 关联表检索 *P* < 5 × 10⁻⁸ 得 91 个
候选 SNP，剔除效应等位基因缺失者后 26 个独立工具变量。
**筛选流程（反向暴露）**：FinnGen R12 汇总统计 *P* < 5 × 10⁻⁸ 得 22,648
个候选位点（含多 rsID 展开），按 *P* 升序距离剪枝（10 kb）后 35 个，
再经等位基因解析与 LD 剪枝后余 **15 个独立工具变量**。

**LD 参考面板**：1000 Genomes phase 3 EUR（经 Ensembl REST API 的
`/ld/human/{rsid}/1000GENOMES:phase_3:EUR` 端点），*r*² 阈值 0.001。
**等位基因解析**：Ensembl `/variation/human/{rsid}`，遍历全部 assembly
mapping 并按染色体与位置匹配、选取等位基因数最少者；回文 SNP 仅在
效应等位基因频率介于 0.42–0.58 时保留；多核苷酸（indel）位点保守剔除。

**工具变量强度**：全部工具变量 F 统计量 > 10——正向暴露 F = 28.3–73.5，
反向暴露 F = 31.0–1373.6。**方法学优势**：暴露来自 UK Biobank（英国），
结局来自 FinnGen（芬兰），**人群完全不重叠，无样本重叠偏倚**。

### 2.5.2 分析方法

**主分析为逆方差加权（IVW）**，并报告加权中位数、MR-Egger（等位基因多效性
校正）与 Simple/Weighted mode 作为稳健性检验。**同一结局亚型分析
（寻常型银屑病、银屑病关节炎）与反向方向（银屑病 → 久坐）按同一流程执行。**

**异质性与多效性**：Cochran's Q 检验（异质性）与 MR-Egger 截距检验
（方向性多效性）。**留一法**（leave-one-out）逐一剔除单个 SNP 重新估计，
用于识别主导结果的位点；**单 SNP 分析**报告每个工具变量的单独估计。

**未执行的 MR 分析及其原因**：
- **多变量 MR（MVMR）**：PA 与久坐的暴露在遗传层面高度相关，
  而 PA 的工具变量在可用汇总统计中数据完整性不足
  （部分研究未提供效应等位基因或频率），无法构建可用的 PA 工具变量集。
  因此**未做 PA 的 MVMR**，久坐的独立效应未经条件化校正。
- **中介 MR（暴露 → CRP/BMI → 银屑病）**：中介变量的工具变量依赖同一套
  不可用的端点，无法构建。
- **Steiger 方向性检验**：未实施。此项为本文的实质性局限，见 §2.5.4。

**代理 SNP**：反向方向 15 个工具变量中有 2 个在结局数据中无直接测量，
由 OpenGWAS 匹配 *r*² > 0.8 的代理 SNP（共匹配 13/15）。

### 2.5.3 结果解读的预设规则

为避免对阴性结果的选择性陈述，**结果解读依以下规则事先约定**：
- 若正向 MR 的 95% CI **覆盖**观察臂点估计，则表述为
  "**未提供支持**"，**不得**表述为"否证"或"反驳"；
- 若反向 MR 显著，则反向因果成立；若不显著，则表述为
  "**未检出反向效应**"，并**明确说明 CI 上限对应的效应量**，
  **不得**表述为"证明不存在效应"。

### 2.5.4 局限（MR 部分）

1. **屏幕时间是自报静坐时间的代理变量**，两者构念仅部分重叠；
   观察臂与 MR 的暴露不一致，这是阴性结果的部分可能解释。
2. **未实施 Steiger 方向性检验**，因此不能从遗传学层面完全排除
   工具变量的方向性。
3. **未做 MVMR**，久坐的独立效应未经条件化。
4. **反向 MR 功效不足以排除小效应**：TV 观看时间的 CI 上限对应
   效应量约 0.9%/单位。
5. **工具变量由本研究自行提取与剪枝**（非使用现成流程），
   虽完全可复现，但与领域标准流程的等价性未做独立验证。
